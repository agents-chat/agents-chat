    Session lock

    Lock the screen after idle time

    After this many minutes with no input, the screen asks for your password. Agents and streams keep going. A visible tab with an agent in flight counts as you being here. 0 turns the lock off. The 30 day session cap still applies.

    Screen recorder

    Record your screen straight into a chat.

    A small Chrome extension records your screen (with optional mic narration) as a compact video and sends it to any conversation here — by default a "📹 Recordings" inbox it creates for you. It reuses your existing login; nothing else to configure.

    1Download & unzipUse the button below, then unzip it somewhere it can stay — Chrome loads the extension from that folder.
    2Open Chrome's extensions pageCopy chrome://extensions below, paste it into Chrome's address bar, and switch on Developer mode (top right).
    3Load itClick Load unpacked and pick the unzipped screen-recorder folder. Pin it via the puzzle-piece menu so it sits on the toolbar.
    4RecordClick the toolbar icon, pick a chat and quality, hit Start recording. Stopping uploads it automatically.
    Good to know: works in Chrome (and Chromium browsers like Edge/Brave via their own extensions page). Recordings are compact — roughly 4–7 MB per minute. The extension signs in as you, so use it in the same browser profile where you're logged in here.
    Kept for 15 days, then archived to backup automatically.
