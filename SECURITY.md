# Security Policy

## Supported versions

Only the newest `0.1.0-beta.x` Community Edition release is actively supported.
Older beta builds may be asked to upgrade before a report is investigated.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
credentials, private chat content, or personal data in a report.

Use GitHub's private vulnerability reporting feature for this repository:
`https://github.com/agents-chat/agents-chat/security/advisories/new`.

Include the affected version, operating system, reproduction steps, expected
and actual behavior, and the smallest safe proof of impact. Remove all secrets
and personal data before attaching logs or screenshots.

I aim to acknowledge a report within three business days, investigate it, and
coordinate disclosure after a fix is available. This personal open-source beta
does not operate a bug-bounty program, and response or fix times are not
guaranteed.
